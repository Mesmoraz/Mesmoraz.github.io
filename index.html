About Me

I'm an SDET on Unity's XR platform team in Bellevue. I've been there since February 2023.

My work is reliability. I build release gates, CI and device-lab automation, and AI agents that do triage a person used to do by hand. Most of it sits where a test result turns into a decision: ship it, block it, or say we don't know yet.

I like working close to the people who use what I build. At Unity I'm the technical point of contact for the Meta runtime across product, QA and engineering. In 2026 I also ran an eight-session advisory engagement directly with a startup founder.

Before software, I taught high school English and history for five years. I still explain things like a teacher: plainly, and with an example.

Projects

Steadygate

A statistical release gate for LLM agents, evals and flaky test suites. Python, open source.

Problem. A gate like "fail if score < 0.80" raises false alarms on noise, and passes quietly when half the suite crashed.

What I built. A CLI that compares each run to your own history and answers PASS, REGRESSION or INCONCLUSIVE. Errors and missing cases can never make a run pass.

Evidence. A live demo you can run in your browser, worked examples for noise, real regressions and crashed runs, and CI on every pull request.

WaNonprofitConnect

A platform for Washington nonprofits. React, TypeScript, .NET.

Problem. Washington nonprofits need a way to be found, say what they need, and hear from groups and businesses that can help.

What I built. A React and TypeScript app on a .NET API with a live SignalR feed and a MapLibre and deck.gl map. It loads public IRS and OSPI data, so every organization on it comes from a real source.

Evidence. Every story ships with a Playwright end-to-end test named after it. GitHub Actions deploys to staging and production on Azure. The roadmap is a JSON file with a written SDLC.

NativeLoc

Native-speaker localization for Android and Linux screen devices. TypeScript, open source.

Problem. Translators get spreadsheets with no context, and kiosks and panels in the field need text that updates without a new build.

What I built. A translator workspace with screenshots and placeholder checks, format adapters, a CLI, device SDKs for Android, Python and JS, and a Docker deployment.

Evidence. The whole app runs in your browser as a live demo. Tests cover the adapters, validation, the server end to end and the JS SDK.

What I Do at Unity

This work is internal, so there are no links. Happy to walk through any of it.

A statistical regression engine

I took a baseline-comparison engine from RFC to production. It has three rule types (absolute, relative delta, MAD outlier) and gives CI a deterministic exit code. A companion tool suggests rules from historical data.

AI agents in production

I wrote a Jenkins MCP server that engineers and agents use to read builds, tests and node health. It has 370+ tests and became team infrastructure. I also run scheduled Claude agents on Kubernetes that classify device-test failures and post triage to Slack, replacing a weekly manual investigation.

A multi-agent review pipeline

Decomposition, architecture, implementation, QA, adversarial review and scored gates, with a person deciding at each gate. On about 13,000 lines of a colleague's pull requests, it caught two silent-green CI risks and a crash path that earlier review missed.

CI at scale

I migrated the XR performance suite into the monorepo: 2,491 CI jobs across four device families. I fixed a 16-day CI blackout with two root causes in two repos, and closed the gaps where crashed runners reported a pass.

Device lab and test health

I own a shared device lab for iOS, Android and Meta Quest. I built a test health dashboard for flakiness, staleness and green streaks. It surfaced 264 failing tests that had no ticket.
